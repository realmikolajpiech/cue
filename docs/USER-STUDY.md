# Cue — krótka próba użyteczności

Status: przygotowany protokół; brak zebranych wyników. Nie zastępuj uczestników wygenerowanymi opiniami.

Zaproś 3–5 chętnych dorosłych i użyj wyłącznie fikcyjnego demo. Wyjaśnij, że AI przesyła te syntetyczne treści do dostawcy. Nie zapisuj nazwisk ani prywatnych wiadomości. Uczestnik może przerwać.

Zadania: znajdź zobowiązanie, sprawdź źródło, skoryguj termin, wygeneruj odpowiedź pasującą do podanej intencji, wyłącz AI w tym czacie. Nie pomagaj, dopóki osoba nie poprosi.

Zapisz anonimowy ID, wykonanie każdego zadania, czas, liczbę potrzebnych wskazówek, liczbę zmian w wybranej sugestii i ocenę naturalności 1–5. Zapytaj: „Co byś zmienił/a przed wysłaniem?” oraz „Który element był niejasny?”. Zapisuj obserwację, nie domyślną interpretację uczuć.

Dla porównania pamięć / brak pamięci losuj kolejność dwóch anonimowo oznaczonych wariantów tego samego scenariusza. Pokaż ten sam kontekst i intencję. Licz preferencję, remisy i poprawki; nie uogólniaj kilku odpowiedzi na populację.
